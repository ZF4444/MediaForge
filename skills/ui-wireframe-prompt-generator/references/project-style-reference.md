# 项目 UI 风格 Reference

版本：0.1.0-llm-reviewed

## 使用边界

- 本文档由 `data/c_en_filter/target/*.txt` 训练描述词的候选规则经大模型审核生成。
- 本文档只提供可复用的视觉规范；目标线框的布局、文字、数量、排列和状态始终优先。
- 页面专属角色、场景、商品、奖励和数值不作为全局风格规则。
- `stable` 可默认使用，`conditional` 仅在适用范围满足时使用。
