# 输出合同

严格输出一段连续的中文描述词：

```text
【<主题/状态>·<美术风格>】背景：...；主视觉：...；UI皮肤：...；图标：...
```

规则：

- 直接以 `【` 开头，并在图标字段结束后结束。
- 保留全部四个字段，使用全角分号分隔。
- 使用顶部左侧、中央偏右、上半屏、下半屏、前景、中景、远景等相对位置词；绝不使用像素坐标。
- 将颜色、材质、光影和特效附着于其所属对象及位置。
- 简单界面约 300–500 个汉字，常规界面约 500–800 个汉字；需要完整覆盖时，复杂界面可以达到约 1000 个汉字。
- 保持目标线框图的画幅、布局、文字、数字、组件数量、排列和交互状态不变。
- 不输出标题、解释、推理、建议、置信度或 Markdown。
- 将线框和参考资料仅作为内部约束；描述词以目标成品 UI 为陈述对象，不出现“线框图、参考图、推断、优先、依据、保留、保持、占位、自动推断”等过程、来源或不确定性措辞。

## 字段写法

- `背景`按远景、中景、前景或全屏底图描述可见环境、空间深度、明暗分区、虚实程度和主要光源；UI 覆盖区域较大时，只描述线框边缘仍可见的底色、纹理、遮罩或环境。
- `主视觉`描述主体的位置、占屏范围、朝向、视角、轮廓、组成部件、颜色、材质、状态、投影和与 UI 的遮挡关系。无法确认专有对象时，使用可见类别、形状和材质，不编造名称或身份；没有证据时写“无独立主视觉”。
- `UI皮肤`按顶部资源栏、标题区、说明区、主面板、页签、卡片/列表、按钮、进度条、提示、角标和底部导航等实际区域描述外形、填充、材质、边缘、体积、文字样式和状态差异。
- `图标`覆盖重要图标，包括顶部资源与功能图标、主视觉附近入口、卡片/奖励格中的不同物品、购买按钮内货币图标、品质框、角标、底部导航图案和红点；每个图标写明位置、所属组件、可见内容、外形、色彩、材质、底板、描边和光效。以确定语气描述最终采用的图标，不交代图标的选择过程。
- 重复组件先描述数量、排列和共同样式，再描述每项有意义的配色、图标、价格、数量、角标、选中、锁定或禁用差异，不得用共同样式掩盖逐项差异。
- 每个补充元素采用“位置＋对象＋外观/内容＋状态或关系”的顺序，并明确其所属区域；特效必须附着于对象或区域，写明产生位置、颜色、范围和遮挡关系。
- 没有明确对象的字段仍须保留，并使用简短、忠实的描述，不虚构内容。相同元素只描述一次；先覆盖所有主要区域，再压缩重复细节。
- 无法确定精确内容时，至少给出可生成的类别、形状、颜色和材质，禁止使用“某个图标”“一些装饰”等无效占位词。
