# 输入模板

当用户没有提供清晰的输入结构，或五个视觉槽位中任一项缺失时，首次使用此模板统一追问。每个槽位都支持文字、图片或两者。

```text
UX 线框图：<image，必填>
主题：<文字、图片或“自动推断”>
背景：<文字、图片或“自动推断”>
主视觉：<文字、图片、“无独立主视觉”或“自动推断”>
UI皮肤：<文字、图片或“自动推断”>
图标：<文字、图片或“自动推断”>
不可变更项：<文字，可选>
禁止出现：<文字，可选>
```

只列出当前缺失或含义不明确的视觉槽位，不要求用户重复已经提供的内容。追问只执行一次：用户下一次回复后，无论是否补全所有槽位，都不得再次追问；根据线框图和已审核的项目风格 Reference 推断剩余缺失值，证据较弱时降低描述具体程度。
