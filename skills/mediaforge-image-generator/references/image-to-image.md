# 图生图与多图参考

## 输入和支持范围

收集修改要求、需要保留的内容，以及用户明确指定的参考图片。保持服装、人物、产品或结构是提示词约束，不能承诺像素级一致或模型必然遵守。

参考图片需已存在于当前用户的画布节点 `images` 中。用户消息中的 `media_references` 可用于定位 `node_id`、`image_index`，但最终仍需读取真实节点确认。数组索引从 0 开始；用户说“第 2 张”对应索引 1。只有预览缩略图而没有原图或文件 ID 时不能提交。

仅有资产库或聊天附件引用、尚未落在画布时，请用户先将图片放入当前画布；当前工具不能凭 URL 创建上传资产节点。不能把一段文字描述、模型自己想象的图片或不可访问的节点当成参考图。

从 `image.text_to_image.targets` 读取所选模型的 `image_input`：

- `supported=true` 表示平台执行链路能传递图片；`max_images` 是链路上限。`scope=transport` 不保证上游具体模型支持编辑，也不保证其原生上限与链路相同。沿用用户指定模型或已知可用配置；上游拒绝图片时报告真实错误，不丢图重试为文生图。
- `supported=false` 时停止该模型的图生图提案；元数据缺失时说明支持情况尚未确定，不仅凭模型名称或文生图能力推断。
- 多图数量超过上限时请用户选择保留的图片或其它明确可用的模型，不截断图片。此路径不提供专用蒙版、重绘强度或区域坐标字段。

## 绑定、选择与顺序

1. 优先新建目标 `image_generation` 节点，参考节点保留原有图片。用户要求基于当前节点输出修改时，将其当作源节点连接到新目标，不能自连接。
2. 在计划中加入 `canvas.connect`，`from_step` 使用参考图真实节点 ID，`to_step` 使用目标创建步骤 ID 或真实目标 ID，`relation` 必须为 `input`。普通 `reference`、`default`、`flow` 关系不会自动传入 API 图片请求。
3. 每个源节点连一次。输入顺序为目标节点已有 `inputNodeIds` 的顺序，随后是画布 `input` 连线的顺序；同一源节点内按 `images` 数组顺序。新目标按用户指定顺序添加连线。相同文件或地址去重，最终角色依次为 `image_1`、`image_2`……，提示词中的“图1/图2”必须与此对应。
4. 默认一个源节点的所有图片都会成为参考。用户只选其中部分图片时，在连线前或后加入 `canvas.update_node_params`，把目标的 `blockedInputRefs` 更新为需排除图片的键列表，格式为 `源节点ID|零基图片索引`。该步骤的 `node.semantic_type=image_generation`，`target_node_id` 可以是刚才的创建步骤 ID。这里只更新节点顶层选择状态，不是模型参数，不能混入新建节点的平铺 `params`。
5. 复用目标时先检查全部现有输入与排除状态，保留明确适用的选择。若现有连线会引入用户未指定的图片，需完整排除这些图片或改建目标；不能只加新连线就运行。当前计划工具没有删线动作。不自行重排用户明确绑定的旧输入。
6. 若用户要求同一源节点多张图片的逆序，当前链路按数组顺序解析，排除列表不能重排；请用户先将选中图片拆成独立源节点，不能声称已改变顺序。

示例：源节点 `source` 有 3 张图，用户仅选择第 2 张。在读取确认真实 ID 后，创建目标 `create-image`，添加 `source → create-image` 的 `input` 连线，并添加以下更新步骤，再添加 `canvas.run_node`：

```json
{
  "id": "select-reference",
  "action": "canvas.update_node_params",
  "target_node_id": "create-image",
  "node": {
    "semantic_type": "image_generation",
    "params": {"blockedInputRefs": ["source|0", "source|2"]}
  }
}
```

以上 ID 只展示关系，运行时必须替换为真实节点 ID 和本次计划步骤 ID。`params` 按工具 schema 要求传对象或编码一次的 JSON 字符串。

## 提交前与失败处理

- 保留原图文件引用，不传缩略图。提交器会核查已注册文件的所有者和删除状态，并拒绝视频、音频等非图片输入。
- 源节点缺失、图片为空、文件失效、所选图片全部被排除、数量超限或参考图无权访问时，停止提交并说明原因；不能去掉图片继续生成。
- 不自动使用目标自身旧输出、历史 `runInputRefs` 或 `runPromptRefs`。文生图复用节点若仍有图片输入，建议新建无图片输入的目标，以免意外执行图生图。
- 完成“新建/更新 → 连线和选图 → 运行”的提案后走平台确认流程。回传真实任务 ID、状态和输出资产；排队不等于编辑完成。
