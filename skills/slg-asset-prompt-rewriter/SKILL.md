# SLG 场景单体提示词强化

收集用户的场景单体描述和期望的输出图像比例，再依据改写规则生成一段中文提示词。本 skill 只改写提示词，不生成图片，也不调用生图工具。

## 必要上下文

### 用户提供

- **场景单体描述**：用户希望生成的单一环境资产及其明确要求，例如主体类型、组件、数量、颜色、材质、结构、观察方向或可见文字。描述应足以识别主体；其他未指定细节可按改写规则合理补全，不作为必填项。
- **期望的输出图像比例**：明确宽与高的关系，例如 `1:1`、`3:2` 或 `2:3`。比例用于确定主体在画面中的位置、组件安排及周围留空，不代表主体自身的宽高比，也不得据此拉伸、压缩或重新设计主体。比例数值不进入最终提示词。

### skill 内置

- **提示词改写规则**：[references/prompt-rewriting-rules.md](references/prompt-rewriting-rules.md)。用户输入齐全后、开始改写前全量读取，作为主体保留、构图适配、细节补全、自检和最终输出的依据。该文件由 skill 提供，不向用户索取。

## 交互策略

- 先检查当前请求及已有对话中的必要用户输入，仅沿用明确适用于当前资产的信息，不将上一项资产的描述或比例自动用于新资产。用户最新指定优先；已提供且仍适用的内容不重复询问。
- 缺少几个必要的用户输入项，就一次性向用户询问这几个；只缺单体描述时询问描述，只缺比例时询问比例，两者都缺时同时询问。
- 内容为空或无法明确识别主体、比例时，视为对应元素尚未提供，针对该项请求补充或澄清。
- 用户明确要求之间存在无法同时满足的冲突时，一次性询问所有冲突项，请用户明确取舍；不得擅自删除、覆盖或折中处理明确要求。普通的未指定细节不属于冲突，无需追问。
- 请求包含多个不相关的独立主体，无法组成一个连贯资产时，询问本次的主资产或主体之间的关系；不得擅自删除对象，也不得强行拼成复合资产。
- 必要用户输入未齐全、明确要求冲突未解决或资产范围未明确时，只输出简短的补充或澄清问题，不提前生成改写提示词，也不擅自为缺失项选择默认值。
- 用户补充后重新检查，只询问仍缺失或仍不明确的必要用户输入项，以及尚未解决的冲突或资产范围问题；两项齐全且明确要求不存在未解决的冲突、资产范围已明确后，进入改写流程。
- 背景和主体之外的周围地面默认透明，不作为必填项，也不为其发起追问。用户明确指定背景或地面时分别保留，未指定的部分仍按透明处理。
- 材质、颜色、视角、光照等非必要细节未指定时，按改写规则补全，不额外扩大必填项。

## 工作流程

1. 按“交互策略”检查并收集“必要上下文”中的两项用户输入；未齐全时先请求补充；如存在明确要求冲突或多个不相关主体，按交互策略澄清后再继续，等待用户回复。
2. 两项用户输入齐全、冲突已解决且资产范围明确后，全量读取 [提示词改写规则](references/prompt-rewriting-rules.md)，将单体描述作为画面内容依据，将期望比例作为内部构图约束。
3. 按规则提取主体及明确约束，组织单体与组件的位置，补全必要结构和表面细节，处理指定可见文字及光照，撰写中文段落。
4. 按规则执行内部最终检查，确认明确要求完整保留、资产连贯、构图适配比例，且未引入风格、制作术语或无关内容。
5. 遵守规则中的“输出约定”，仅返回一段中文提示词，不输出分析、解释或内部步骤。补充用户输入及澄清冲突或资产范围的阶段不受最终中文段落格式限制。
