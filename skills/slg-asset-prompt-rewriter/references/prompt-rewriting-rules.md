# 单一 SLG 场景资产提示词改写

将用户的生图请求改写为一段英文，客观描述单一环境资产的可见内容。SLG 游戏环境概念资产仅作为内部范围约束，不得出现在最终提示词中。以下推理与检查均在内部完成；只返回最终提示词，不生成图片，也不调用生图工具。

## 主体范围与透明背景

图像以透明背景呈现单体资产。透明背景作为内部输出约束，最终提示词只描述主体及其附属组件，不追加背景描述或“透明背景”等制作措辞。主体周围留空仅用于保持轮廓完整，不代表需要补充任何背景内容。

不描述天空、远景、背景颜色、背景纹理、透明棋盘格或独立的周围地面。基座、地基、支撑平台以及地形资产自身的土石属于主体，可以描述；不得为解释物理支撑而额外添加地面或景观。用户明确要求与透明背景相冲突的环境内容时，按 SKILL.md 的交互策略澄清，不悄悄删除明确要求。

## 提取主体与约束

识别主要资产，例如建筑、工事、资源设施、纪念物、地形、植被组或环境道具。保留用户明确指定的全部画面内容，包括物体名称、数量、颜色、材质、结构特征、空间关系、观察方向以及需要出现在画面中的文字。

将画幅比例与画面内容分开提取，比例仅用于指导构图。风格、媒介、渲染方式、画质、分辨率和输出格式等制作指令不得进入画面描述。

需要出现在画面中的文字必须逐字复制，保留原始语言、标点和空格，不得翻译。

## 根据可用空间组织构图

- 宽度大于高度时，优先让已有组件横向排列，使相邻结构之间清晰分离，并在主体左右留出足够空间。
- 高度大于宽度时，优先呈现从基座、主体到顶部的清晰结构顺序，并在上下留出足够空间。
- 宽高相等或接近时，优先采用紧凑布局，在主体周围保留均衡空间。

通过具体的位置、可见比例、组件关系和周围留空表达这些选择。不得输出画幅比例数值、画布尺寸、像素数量、分辨率或“横向构图”“竖幅画面”等方向标签。

保留资产的身份和用户明确指定的比例。即使可用空间更宽，高塔仍然是高塔；即使可用空间更高，宽阔堡垒仍然保持宽阔。不得为了填满空间而拉伸、压缩、复制或重新设计主体。优先调整位置、未指定的观察方向和周围留空，再考虑调整未指定的结构比例。

除非用户明确要求裁切或特写，否则保持整个主要资产可见。屋顶、塔楼、枝条、平台等突出部分周围需要留出空间，使其边界清楚。不得用无关物体或景观填充空白。画幅比例须先按 SKILL.md 的交互策略收集；不得自行编造比例数值。

## 形成一个连贯资产

围绕一个可识别的主要资产组织描述；附属组件和必要支撑结构属于同一资产。用户明确要求多个相关结构或物体时，只要关系允许，就将其组织为连贯的复合资产，不得悄悄删除已指定内容。多个不相关的独立主体须先按 SKILL.md 的交互策略明确主资产或彼此关系，不得强行拼成复合资产。

以具体、合理的特征补全未指定细节，使其服务于资产的身份、功能、环境和建造方式。补全内容不得覆盖用户明确要求，也不得改变资产类型、主要轮廓、明确指定的组件数量或功能。不得将简短请求扩展为无关的景观、聚落、叙事场面或多个独立资产。只有用户要求或解释资产确有必要时，才加入与主体直接相关的人物、车辆、标牌或装饰物，不添加远景；可读文字仍必须由用户明确要求。

保持主体轮廓、主要组件和已有基座清晰可辨。通过主体自身的结构和连接关系说明物理支撑，不借助背景或周围地面说明位置。

## 描述结构与表面

开头直接点明资产及其最显著的可见特征。必要时交代位置、观察方向、可见侧面、整体比例及与基座的连接关系。遵循用户指定视角；未指定时，选择能展示主体结构和重要组件、避免不必要重叠的视角。

按空间顺序描述：整体形态、基座与下部结构、主体、上部结构、附属组件、小型可见细节。需要时明确“位于基座处”“沿左侧墙体”“入口上方”“塔楼后方”“屋顶下方”等位置关系。不要强行在每个边缘或角落添加细节。

描述可观察的属性：

- 形状及相对于相邻组件的比例。
- 材料、接缝、支撑和构件连接方式。
- 表面颜色及物理纹理。
- 开口、屋顶、墙体、平台、楼梯和固定设施。
- 合适的磨损、损坏、沉积物或植被。
- 能说明资产用途的可见功能构件。

保留明确指定的颜色；未指定颜色时，选择符合材料和主体的具体颜色。物理纹理可以是木纹、石材裂缝、金属腐蚀或布料褶皱，不得描述笔触、纸张颗粒等图像制作纹理。

使用具体名词和可识别的组件，不使用“各种细节”“很多装饰”等模糊措辞。将未指定内容落实为一种一致描述，不提供多个备选，不反复使用“也许”“可能”“似乎”等不确定措辞。被遮挡的组件只描述可见部分及其遮挡关系。

## 可见文字与光照

只有用户明确要求时才加入可读文字，不编造标签、横幅、铭文或标牌。对每个指定文字字符串，描述其位置、相对大小、颜色和实际载体，并将原文放在英文半角双引号中。

通过主体表面的可见效果描述光照，包括来光方向、被照亮的表面、组件之间的遮蔽与投射阴影、高光和反射。不添加落在主体之外的地面投影，也不通过反射引入未指定的背景景物。光照效果必须符合结构几何和材料特性，不使用“电影感”“戏剧性”“影棚摄影”等光照风格标签。

## 内部最终检查

确认所有明确内容均已保留，背景相关冲突已按交互策略解决，描述仅涉及主体及其附属组件，未引入背景、周围地面或主体之外的投影，新增细节服务于同一资产，构图适应用户提供的比例，同时未扭曲几何形态或删除指定特征。检查结构连接、尺度、材料表现、遮挡、阴影及反射是否一致。对于刻意违反现实或具有幻想性质的资产，保留指定特征，使其他可见关系保持连贯。

删除以下内容：艺术风格或审美分类；媒介、技法、软件或渲染方式；SLG 游戏、概念设计、制作流程或预期用途；画幅比例数值、画布尺寸、画面方向标签、分辨率或像素信息；“杰作”“8K”“高度精细”等质量强化词；面向画师、模型或用户的指令；未要求的负面提示词列表；关于情绪、美感或艺术质量的抽象评价。资产自身明确指定的尺寸和结构比例属于画面内容，例如十米高的塔、两米宽的入口，必须保留。上述排除项针对描述性措辞和制作要求：用户明确要求显示在资产上的文字仍须逐字保留。

保留有用的具体位置和周围留空描述。以最后一个有用的可见细节结束，不追加关于风格、情绪或构图的泛泛总结。

## 输出约定

只输出改写后的提示词值，以纯文本呈现为一个连贯的英文段落。不得输出 JSON、字段名、包围整个段落的引号、Markdown、标题、解释或内部步骤。只有指定的画面可见文字可以使用其他语言，其原文保留在英文半角双引号中。

使用现在时的陈述句，以观察者口吻描述完成后的画面，不使用“创建”“渲染”“确保”“AI 应当”等命令句。优先描述主体形态和识别特征，再描述辅助结构与表面细节。长度随资产复杂度调整，不设固定字数，不凑字数，不重复，不添加不必要的修饰。
